# 開発・AIコーディング指示書 (INSTRUCTIONS.md)

本ドキュメントは、今後AIや開発者が本プロジェクト（`MyNKF`）のコードを修正・追加する際に遵守すべきコーディングスタイル、エラーハンドリング方針、設計原則、および出力フォーマットについて規定するものです。

---

## 1. 命名規則
Rustの標準的なコードスタイルガイドラインに従います。

| 対象 | 規則 | 例 |
| :--- | :--- | :--- |
| **変数、関数、メソッド、引数、モジュール** | `snake_case` (小文字＋アンダースコア) | `guess_encoding`, `to_enc`, `utf8_score` |
| **型、構造体、列挙型、トレイト** | `PascalCase` (単語の頭文字が大文字) | `Encoding`, `LineEnding`, `MyNkfGuiApp` |
| **定数、スタティック定数** | `SCREAMING_SNAKE_CASE` (大文字＋アンダースコア) | `MAX_GLOB_FILES`, `JIS_TO_UNICODE_BASE64` |
| **マクロ** | `snake_case!` | `todo!`, `matches!` |
| **ドキュメント・ファイル名** | `UPPER_SNAKE_CASE` (大文字＋アンダースコア) | `ARCHITECTURE.md`, `INSTRUCTIONS.md`, `README_JA.md` |

---

## 2. エラーハンドリングの方針
- **パニックの回避**: ライブラリ（`src/lib.rs`）およびCLI版（`src/main.rs`）において、`unwrap()`、`expect()`、`panic!` の使用は極力避けてください。
- **戻り値によるエラー伝播**: エラーが想定される処理では、`Result<T, E>` や `Option<T>` を戻り値として返し、上位でエラーハンドリングを行います。
- **文字マッピング失敗のフォールバック**: マッピングテーブルに存在しない外字や特殊文字が検出された場合、`??` などの安全なデフォルト文字にフォールバックして処理を継続します。

---

## 3. コンポーネント・モジュールの分割基準
- **`src/lib.rs` (コアライブラリ)**: 文字コードの自動判定、デコード・エンコード、改行コードの検出、ワイルドカード展開などを集約。
- **`src/main.rs` (CLIエントリーポイント)**: 引数のパース、ファイルおよび標準入出力のストリームの読み書きを担当。

## 5. 品質管理・自動テストと事前検証ルール (モジュール化退避)
- **ユニットテストの追加・拡充**: 新機能追加やコアロジック変更時は `src/tests.rs` にテストを追加・拡張。
- **回帰テストの実行**: コード変更後は `cargo test` を実行し、全自動テストケースがパスすることを確認。
- **モジュール分割**: 単一ファイルが **1,000 行** を超えた場合はモジュール分割リファクタリングを検討・提案。
- **ローカル事前検証**:
  1. `cargo test` （テスト合格）
  2. `cargo clippy --all-targets -- -D warnings` （Clippy警告・エラーゼロ）
  3. `cargo fmt --check` （コードフォーマット完全準拠）
  4. `cargo doc --no-deps --document-private-items` （Rustdocビルドエラー・警告ゼロ）
- **デスクトップアプリ（eframe/egui）開発ガイドライン**:
  - **ウィンドウの影と枠の消去**: 透過ウィンドウの枠や影を防ぐため `eframe::NativeOptions` で `decorated: false`, `transparent: true` を指定。
  - **ドラッグ操作**: タイトルバー非表示のためカスタムUIドラッグ時に `ctx.send_viewport_cmd(egui::ViewportCommand::StartDrag)` を呼び出す。
  - **二重起動の防止**: `fn main()` 冒頭で Named Mutex による多重起動防止処理を実行。
  - **リリースサイズ最適化**: `Cargo.toml` の `[profile.release]` に `opt-level = 'z'`, `lto = true`, `strip = true` などを適用。
