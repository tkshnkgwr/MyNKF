# 開発タスク管理表 (TODO.md)

本ドキュメントは、`MyNKF` プロジェクトの開発の「現在地（実装済み機能）」、直近で対応が必要な「仕掛かり・予定タスク（In Progress / Todo）」、および将来的な「拡張提案（Backlog）」を管理するロードマップです。

---

## 1. 実装済みの機能一覧 (Done)

### 1.1 コアライブラリ (`mynkf` - `src/lib.rs`)
- [x] **文字コード判定 (Guess)**: ASCII, UTF-8, EUC-JP, Shift_JIS, BINARY の高精度な自動判定。
- [x] **改行コード判定**: LF, CRLF, CR, MIXED, NONE の自動判定。
- [x] **文字コード変換**: UTF-8 ⇆ EUC-JP ⇆ Shift_JIS の相互変換（JIS X 0208マッピングテーブルに基づく）。
- [x] **改行コード変換**: 目的のエンコーディングに応じた改行コードの正規化、および LF / CRLF への強制変換。
- [x] **半角カタカナの保持**: Shift_JIS半角カタカナの他エンコーディングへのマッピング・保持。
- [x] **外字フォールバック**: 定義外の文字が入力された際、処理を止めずに `??`（疑問符2つ）へ安全に置換。
- [x] **ワイルドカード（グロブ）展開**: Windows環境下での `*` や `?` パターンの一括展開処理（最大100ファイル制限）。
- [x] **Cargo Features による機能分離**: `Cargo.toml` に `cli` および `gui` フィーチャーを追加し、CLI単体ビルド時のGUI依存クレート（eframe/egui/rfd）省略・高速コンパイルを実現。
- [x] **テストコードの別モジュール分離**: `src/lib.rs` 内の単体テストコードを `src/tests.rs` に分離し、ファイル行数を986行から786行へと削減・スリム化。
- [x] **自動単体テスト**: `cargo test` による17個の主要ロジック検証テスト。

### 1.2 CLI版 (`mynkf` - `src/main.rs`)
- [x] **コマンドオプション実装**: `-w`, `-s`, `-e`, `-g`, `--line`, `--size`, `-d`, `-c`, `-h`, `-v`, `--versio` の実装。
- [x] **標準入出力連携**: 引数省略時に標準入力からデータを読み込み、標準出力へストリーム出力。
- [x] **複数ファイル処理**: ワイルドカードで展開された複数ファイルを順次処理。

### 1.3 GUI版 (`mynkf-gui` - `src/bin/mynkf-gui.rs`)
- [x] **二重起動防止**: Win32 Named Mutex による多重プロセスの即時終了。
- [x] **枠なし・影なしウィンドウ**: Win32 DWM API の直接制御による透過フラットUIデザイン。
- [x] **カスタムタイトルバー**: 自作ヘッダーバーおよびドラッグによるウィンドウ移動（`ViewportCommand::StartDrag`）。
- [x] **日本語フォント動的ロード**: `C:\Windows\Fonts` から `meiryo.ttc` 等を走査・ロードし、日本語豆腐化を防止。
- [x] **ファイル一括変換**: ファイルのドラッグ＆ドロップまたはファイルダイアログによる追加、文字コード/改行自動解析、一括上書き保存。
- [x] **テキスト直接変換**: テキスト入力に対するリアルタイム変換プレビュー、および模擬デコード経由のクリップボード転送。

## 2. 直近のタスク (In Progress / Todo)

- [ ] **親リポジトリ共有ライブラリ `common_lib` 依存の整理**:
  - `../common_lib` に対する相対パスでの依存を行っているため、CI/CD やローカルビルド時の準備手順が複雑化している。サブモジュール化するか、あるいは依存を排除できないかの検討。
- [ ] **GUI版でのウィンドウ状態（サイズ・位置）の保存機能**:
  - アプリケーション起動時に、前回のウィンドウサイズや表示位置を維持する設定保存機能の追加。
- [ ] **GUI版テキスト直接変換での文字コード別表示プレビューの強化**:
  - 現在はクリップボード転送の際のみ模擬デコードが行われるが、画面上のプレビューテキストエリア自体で「Shift_JISで保存された場合のバイト表現や代替文字化けプレビュー」などをリアルタイム表示する機能。
- [ ] **他プラットフォーム（macOS/Linux）でのGUI動作検証とフォールバック**:
  - 現在は Win32 API 依存部分を `#[cfg(target_os = "windows")]` で隠蔽しているが、他OS上でビルドした際のフォント読み込みエラーやウィンドウ挙動（影の有無など）の確認と、他OS向けフォールバック処理の最適化。
- [ ] **テストカバレッジの向上**:
  - `expand_wildcard` のエッジケース（特殊文字を含むパス等）のテストケース追加、および UI 側のロジック分離によるテストコード化。

## 3. 今後拡張の余地がある機能の提案 (Backlog)

- [ ] **対応文字コードの追加**:
  - 伝統的な電子メール等で用いられる `JIS` (ISO-2022-JP)、および `UTF-16` (LE/BE)、`UTF-32` への変換・判定サポート。
- [ ] **改行コード `CR` への変換オプション追加**:
  - `--cr` オプションを追加し、古いmacOS向けの改行コード変換にも明示的に対応（判定はすでに実装済みだが、出力指定は現在 LF と CRLF のみ）。
- [ ] **コアライブラリ `mynkf` の WebAssembly (Wasm) 化**:
  - コアロジックを Wasm ビルドし、Webデスクトップシミュレータの変換ロジックをこれに置き換える。これにより、WebUI 上でも CLI/GUI 版と寸分違わない正確な変換・判定シミュレーションが可能になる。
