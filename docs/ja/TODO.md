# 開発タスク管理表 (TODO.md)

本ドキュメントは、`MyNKF` プロジェクトの開発の「現在地（実装済み機能）」、直近で対応が必要な「仕掛かり・予定タスク（In Progress / Todo）」、および将来的な「拡張提案（Backlog）」を管理するロードマップです。

## 1. 実装済みの機能一覧 (Done)

### 1.1 コアライブラリ (`mynkf` - `src/lib.rs`)

- [x] **文字コード判定 (Guess)**: ASCII, UTF-8, EUC-JP, Shift_JIS, BINARY の高精度な自動判定（制御文字チェック・UTF-8厳格検証・JIS座標スコアリング）。
- [x] **改行コード判定**: LF, CRLF, CR, MIXED, NONE の自動判定。
- [x] **文字コード変換**: UTF-8 ⇆ EUC-JP ⇆ Shift_JIS の相互変換（JIS X 0208 全6,953文字の完全マッピングテーブルに基づく）。
- [x] **改行コード変換**: バイト列レベルでの直接改行コード変換（`convert_line_endings_raw`）および再エンコード時の改行正規化。
- [x] **半角カタカナの保持**: Shift_JIS半角カタカナの他エンコーディングへのマッピング・保持。
- [x] **外字フォールバック**: 定義外の文字が入力された際、処理を止めずに `??`（疑問符2つ）へ安全に置換。
- [x] **ワイルドカード（グロブ）展開**: Windows環境下での `*` や `?` パターンの一括展開処理（最大100ファイル制限）。
- [x] **テストコードの別モジュール分離**: `src/lib.rs` 内の単体テストコードを `src/tests.rs` に分離し、ファイル行数を1,000行未満へとスリム化。
- [x] **自動単体テスト**: `cargo test` による21個の主要ロジック検証テスト。
- [x] **egui (GUI機能) の完全廃止と CLI 一本化**: 不要な GUI 関連ロジック・依存関係を排除し、純粋な std CLI アプリに統合・最適化。

### 1.2 CLI版 (`mynkf` - `src/main.rs`)

- [x] **コマンドオプション実装**: `-w`, `-s`, `-e`, `-g`, `--line`, `--size`, `-d`, `-c`, `-h`, `-v`, `--versio` の実装。
- [x] **標準入出力連携**: 引数省略時に標準入力からデータを読み込み、標準出力へストリーム出力。
- [x] **複数ファイル処理**: ワイルドカードで展開された複数ファイルを順次処理。
