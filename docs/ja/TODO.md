## 1. 実装済みの機能一覧 (Done)

### 1.1 コアライブラリ (`mynkf` - `src/lib.rs`)

- [x] **文字コード判定 (Guess)**: ASCII, UTF-8, EUC-JP, Shift_JIS, BINARY の高精度な自動判定（制御文字チェック・UTF-8厳格検証・JIS座標スコアリング）。
- [x] **改行コード判定**: LF, CRLF, CR, MIXED, NONE の自動判定。
- [x] **文字コード変換**: UTF-8 ⇆ EUC-JP ⇆ Shift_JIS の相互変換（JIS X 0208 全6,953文字の完全マッピングテーブルに基づく）。
- [x] **改行コード変換**: バイト列レベルでの直接改行コード変換（`convert_line_endings_raw`）および再エンコード時の改行正規化。
- [x] **半角カタカナの保持**: Shift_JIS半角カタカナの他エンコーディングへのマッピング・保持。
- [x] **外字フォールバック**: 定義外の文字が入力された際、処理を止めずに `??`（疑問符2つ）へ安全に置換。
- [x] **ワイルドカード（グロブ）展開**: Windows環境下での `*` や `?` パターンの一括展開処理（最大100ファイル制限）。
- [x] **テストコードの別モジュール分離**: `src/lib.rs` 内の単体テストコードを `src/tests.rs` に分離。
- [x] **モジュール分割リファクタリング**: 肥大化していた `src/lib.rs`（約1,000行）を責務別サブモジュール（`types`, `newline`, `glob`, `table`, `guess`, `convert`）へ完全分割し、`src/lib.rs` を再エクスポートファサード化。全ソースファイルを310行以下にスリム化。
- [x] **自動単体テスト**: `cargo test` による 25 個の主要ロジック・境界ケース検証テスト（+ Doctest 14 件）。
- [x] **egui (GUI機能) の完全廃止と CLI 一本化**: 不要な GUI 関連ロジック・依存関係を排除し、純粋な std CLI アプリに統合・最適化。
- [x] **未使用 `common_lib` 依存の完全排除**: `Cargo.toml` および GitHub Actions CI/CD ワークフローから未使用の `common_lib` 相対パス依存を削除し、純粋な標準ライブラリ限定（外部依存ゼロ）構成を確立。

### 1.2 CLI版 (`mynkf` - `src/main.rs`)

- [x] **コマンドオプション実装**: `-w`, `-s`, `-e`, `-g`, `--line`, `--size`, `-d`, `-c`, `-h`, `--help`, `-v`, `--versio` の実装（重複指定時は後勝ち）。
- [x] **二段階ヘルプ表示**: `-h`（構文・主要オプション一覧の簡潔ヘルプ）と `--help`（カテゴリ別詳細・注意事項・使用例を含む詳細ヘルプ）の表示分離。
- [x] **標準入出力連携**: 引数省略時に標準入力からデータを読み込み、標準出力へストリーム出力。
- [x] **複数ファイル処理**: ワイルドカードで展開された複数ファイルを順次処理（ファイル読込エラー時は終了コード `1`）。
- [x] **RustDoc・ドキュメント整備**: 全公開型・関数・定数に完全なドキュメントコメントと使用例コード（Doctest 14件全合格）を完備。各種設計ドキュメントの完全同期。
