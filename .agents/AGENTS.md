# AI Agent Instructions for MyNKF (Gem)

本プロジェクトにおける大賢者の開発指示書です。
最優先ルール（コミット禁止・テーブル整列等）は [[GEMINI.md]] を参照してください。

## 🎯 開発・品質ルール

- **技術解説方針（他言語経験への配慮）**:
  - ユーザーは他言語経験をお持ちですが、Rust/React/TypeScript固有の言語仕様・専門用語（所有権、ライフタイム、トレイト、フック等）には不慣れです。
  - 難解な専門用語を多用せず、一般的・共通的なプログラミング概念（参照、インターフェース、モジュール、関数など）に置き換えるか、直感的に理解できるよう分かりやすく補足・解説を添えること。
- **事前検証とドキュメント同期**:
  - 開発およびドキュメント更新の際は、必ず [`docs/ja/INSTRUCTIONS.md`](../docs/ja/INSTRUCTIONS.md) に記載されている「対象ドキュメント一覧と更新ルール」および「品質管理・事前検証プロセス」に厳格に従って検証・同期を行うこと。
- **コード規模とリファクタリング**:
  - 単一のソースファイル（`src/lib.rs` 等）のコード行数が **1,000 行** を超過した場合、関心事・役割に応じたモジュール分割リファクタリングを積極的に提案・推進すること。
